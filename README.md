# random-synth-parts
Monorepo for small synth parts that aren't interesting enough to get their own repo

## Roland MC-505 Knob Reinforcements
These 3d printable plates fit over top of the potentiometers in the Roland MC-505 to help prevent them from getting smashed.

## BOSS Micro Rack Buttons
These 3d printable button caps fit the power/effect buttons on the front of BOSS Micro Rack effects modules, and the input level (and similar) buttons on the rear.

These should print easily face-up, though some tweaking may be needed to get a satisfying click-fit on the button shafts.

## Casio SK-5 Switch Caps
These 3d printable button caps fit the volume and Mode / Part Tone sliders on the Casio SK-5 and identical Realistic Concertmate 650.

These can be printed face-up on an FDM printer with supports, but will probably come out a bit better on a resin printer.

![Casio SK-5 Switch Caps](Casio%20SK-5%20Switch%20Caps/sk5-switch-caps.jpeg)

## Roland D-70 Foot
This is a foot for the Roland D-70. It's designed to be printed in hard plastic like PLA or PETG and has an M6x1 threaded hole.

You should probably just buy some generic rubber feet and use those instead. I made this because I ran out and didn't feel like waiting for a delivery.

## Boss SE-50 SE-70 Screen Spacer
This spacer bracket is designed to stick to the back of an off-the-shelf 16x2 LCD module with thin double-sided tape. The bracket can then be stuck to the metal frame inside a BOSS SE-50 or BOSS SE-70, and likely many other models, possibly with some modification to account for different clearances.

Remember to reverse the VCC and GND pins on the cable when using a modern LCD unit. You should also avoid using the original backlight power connector, as the original circuit delivers a much higher voltage than is required for modern panels, which usually come pre-wired to draw the backlight power from the main ribbon cable anyway. Be sure to disable the shunt regulator on the SE-50's backlight supply so that it does not burn up the zener diode over time.
